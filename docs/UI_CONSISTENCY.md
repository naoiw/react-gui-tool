# UI 共通方針

`photo-editor` および `naoiw.github.io` と同じサイトクロームの寸法を維持します。配色はライト／ダークの2種類を持ち、初回はライトモードです。別のUIフレームワークは導入せず、`src/index.css` のCSS変数とクラスで統一します。

## サイトクローム

| 項目 | 設定 |
| --- | --- |
| 最大コンテンツ幅 | 1180px |
| 横パディング | 28px（620px 以下は17px） |
| ヘッダー高さ | 78px（620px 以下は67px） |
| 背景色 | ライト `#f5f7fb` / ダーク `#0b1220` |
| パネル | ライト `#ffffff` / ダーク `#172337` 系 |
| 境界線 | ライト `#d8e1eb` / ダーク `#304157` |
| 本文 | ライト `#24334a` / ダーク `#edf3fb` |
| 補助テキスト | ライト `#61768e` / ダーク `#a0b2c8` |
| アクセント | ライト `#147d75` / ダーク `#70ddc7` |

## テーマ切替

- `src/index.css` の `:root` をライト、`:root[data-theme="dark"]` をダークとして、すべての配色をCSSカスタムプロパティで定義
- ヘッダーのボタンから切替し、`react-gui-tool-theme` を `localStorage` に保存する。未保存ならライトモード。OSのテーマ変更には自動追従しない
- 保存済みのテーマは `index.html` の小さなスクリプトでReact起動前に適用し、初回描画のちらつきを防ぐ
- ボタンは切替先のテーマを表示し、`aria-label` と `title` に切替先を明示する
- Rechartsの軸文字色・フォーム・状態バッジ・エラー表示はテーマトークンに追従。チャンネルの線色は固定のまま
- Web Serialや波形バッファはテーマ切替時に再生成しない

## フッターの共通基準

- 上下の余白: 28px / 32px、フォントサイズ: 12px、font-weight: 500、letter-spacing: .02em
- 区切り線: ダーク `#233248` / ライト `#dce4ee`。コンテンツ幅の内側にのみ表示し、ページ全体には伸ばさない
- リンク表記: `GitHub ↗`。右側に配置し、狭い画面でもリンクを途中で改行しない
- `.site-shell` / `.page-container` は縦向きFlex構成、`.site-main` は余白を伸ばしてフッターを最下部に配置
- モバイル（620px以下）では `.site-footer` の折返しを許可する

## コンポーネント

- `.site-header` / `.site-footer` — 他ツールと位置・サイズを統一
- `.theme-toggle` — ヘッダーのライト／ダーク切替
- `.status-grid` / `.status-card` — 接続状態と直近の受信値
- `.panel` / `.waveform-card` — 角丸・境界線・背景を共通化
- `.field-label` / `.field-input` — COMポート、ボーレート、数値入力
- `.button` / `.button--primary` / `.button--secondary` — 操作ボタン
- `.channel-toggle--on` — 表示チャンネルの選択状態
- `.error-message` — `role=alert` の単一エラー表示

画面幅 750px 以下では受信ステータスとシリアル設定を縦配置にします。620px 以下では入力欄を1列にして、ボタンとグラフ設定を折り返します。

`recharts` の線色は `channelConfig.ts` の設定を維持し、軸ラベルだけをダーク背景に合わせます。Start / Stop は未実装であり、無効化されたままです。

UI は一般的なデザインの共通部分のみ統一し、シリアルポート設定や波形の機能は既存仕様を維持します。
